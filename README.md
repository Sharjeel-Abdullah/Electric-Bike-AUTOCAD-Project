# Electric Bike Assembly Design

A complete CAD assembly, mechanical layout, and cost analysis for a commuter electric bike designed in **AutoCAD**.

---

## 📌 Features & Contents

* **AutoCAD Assembly:** Complete 2D/3D `.dwg` drawings for the chassis, motor mounts, and component packaging.
* **Cost Estimation:** Itemized Bill of Materials (BOM) including component pricing and material selection.
* **Design Renders:** Visual preview sheets and exported CAD renders for quick viewing.
